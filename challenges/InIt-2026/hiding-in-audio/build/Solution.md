# The Build

The idea is pretty simple, you can add messages in the spectogram of any audio.
I combined a generic IRCTC announcement with a audio file that has the spectogram.

# The Solution

1. Use Audacity to open the audio file.
2. Switch to Spectogram view, flag will be visible.


Flag: `InIt{h1d1ng_f1l3s_1n_4ud10}`
